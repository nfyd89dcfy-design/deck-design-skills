# Стиль "Dell-96 x Liquid Glass"

Гибрид двух референсов, выбранных заказчиком:

1. **Dell 1996** ([DESIGN.md](https://getdesign.md/dell-1996/design-md), MIT-подборка VoltAgent): страница в черной рамке, плоские цветные "ленты-карточки" каталожных оттенков, тяжелые заголовки капсом, текст антиквой, жесткие границы, нулевой радиус, жесткая тень-фаска вместо мягкой.
2. **Liquid Glass** ([ECC liquid-glass-design](https://github.com/affaan-m/ECC/blob/main/skills/liquid-glass-design/SKILL.md)): стекло как слой над контентом.

Подключение: `tokens.css`, `glass.css`, затем `style-dell96-glass.css`. На `<body>` поставить `data-style="dell96"`
(линтер знает стиль: допускает подписи капсом и цветные плоскости под стеклом).
Эталон: `examples/deck-dell96.html`.

## Главный принцип гибрида

**Все плоское и квадратное, все стеклянное мягкое и скругленное.** Контраст между двумя
языками и есть идея. Стекло не копирует эстетику Dell, а лежит поверх нее.

## Что берем у Dell

| Элемент | Правило |
|---|---|
| Рамка | Черная рамка 20px вокруг страницы (на холсте 1920x1080), верхняя полоса 76px с лого и названием раздела. Рамка у страницы, **не у фото** |
| Блок-заголовок | Плоский цветной блок, заголовок Montserrat 900 капсом, обводка 2px |
| Лента | Белая шапка (Montserrat 800 капсом) + цветное тело (Tinos), обводка 2px, радиус 0 |
| Оттенки | 8 каталожных: olive, sage, salmon, peach, lime, sky, steel, peri. Один оттенок на одну линейку, без градиентов и прозрачности |
| Шрифты | Montserrat (замена Arial Black и Helvetica, есть кириллица) + Tinos (замена Times New Roman, есть кириллица). Две гарнитуры |
| Фото | Жесткий прямоугольник, радиус 0, жесткая тень `8px 8px 0 #000`. Допускается выход за край ленты вверх и вниз ("наколото на пробку") |
| Стикер | Желтый плоский, обводка 2px, жесткая тень, поворот около -8 градусов. Один-два на колоду |
| CTA | Красная панель (#e91d2a), текст кремовый. **Одна на колоду.** Красный нигде больше не используется |

## Что берем у Liquid Glass

| Правило ECC | Как у нас |
|---|---|
| Стекло для интерактивного и функционального слоя: тулбары, карточки, кнопки | Пилюля-метка, круглая печать, плашка с главной цифрой, полоса-подпись. Не заголовки и не вся лента |
| Не стекло на каждом элементе | 1-2 стеклянных объекта на слайд |
| Группа стекол в одном контейнере (слияние) | Соседние стеклянные элементы собирай в один `.glass`-контейнер с одним размытием |
| Тонировка для акцента | `.glass--light` над цветом ленты, оттенок виден сквозь стекло |
| Не ставить непрозрачный фон под стекло | Под стеклом всегда цветная лента или фото |
| Контраст текста на стекле | Текст на стекле черный на светлом стекле, проверять глазами |
| Не вкладывать стекло | Стекло в стекле запрещено (линтер) |

Реализация ECC для SwiftUI и UIKit (`glassEffect`, `GlassEffectContainer`, морфинг) на статичных
слайдах не применима. Берем принципы, а CSS остается нашим (`glass.css`).

## Что НЕ берем из Dell

- Размеры 12-14px: на холсте 1920 текст от 24px.
- Синие подчеркнутые ссылки и растровые GIF-иконки.
- Запрет на скругления и тени для стеклянных объектов: он относится только к плоским элементам.

## Размещение стекла (проверено на примере)

- Стекло над цветной лентой: хорошо видно размытие и тонировку.
- Стекло над белым фото на белой странице: незаметно, не ставь.
- Полоса-подпись крупным словом (например, "в среднем") над двумя лентами: размер шрифта подбирай так, чтобы слово занимало ширину полосы, а не растягивай трекингом.
- Лента с фото: фото в правой части, стеклянная метка на стыке цветного тела и фото.

## Шаблоны слайдов

1. Обложка: блок-заголовок, лента-описание, две ленты с цифрами, фото справа, стеклянная печать.
2. Метрики: блок + три ленты (цифра 168px, пояснение 38px), стикер на одной.
3. Модель: лента с шапкой-названием, параметры слева, фото справа.
4. Условия: фото + ленты параметров + ленты условий + красная CTA.
